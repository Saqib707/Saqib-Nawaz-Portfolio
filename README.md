# Saqib Nawaz — Digital Marketing Portfolio

A responsive personal portfolio website for Saqib Nawaz, BBA student at Iqra University, Karachi.

## Features
- Crisp typography with a white and dark-navy visual identity
- SN. monogram branding
- Illustrated marketing dashboard in place of a portrait
- Animated navy expertise and portfolio concept cards
- About, Expertise, Portfolio Concepts, Education, and Contact sections
- Mobile responsive and reduced-motion accessible
- Contact: saqibnawaz707@gmail.com

## Publish on GitHub Pages
1. Create a public GitHub repository (for example, `saqib-portfolio`).
2. Upload `index.html` and `README.md` to the repository root.
3. Open Settings → Pages → Build and deployment → Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. Open `https://YOUR-USERNAME.github.io/saqib-portfolio/` after deployment finishes.

Portfolio projects are clearly labeled as illustrative concepts, not real client work.
